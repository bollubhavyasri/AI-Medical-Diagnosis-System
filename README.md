AI Medical Diagnosis System

An intelligent healthcare web application built using Streamlit and Python that predicts possible diseases based on user-entered symptoms.
The system also provides disease descriptions, precautions, interactive charts, chatbot support, and downloadable medical reports.

🚀 Features
✅ Disease Prediction
Predicts possible diseases from symptoms
Rule-based symptom matching system
Displays confidence percentage
✅ Disease Information
Disease description
Recommended precautions
Symptom matching display
✅ AI Chatbot Assistant
Sidebar medical assistant
Handles common symptom queries
Interactive user conversation
✅ Visualization Dashboard
Disease probability chart
Symptom frequency chart
✅ PDF Report Generation
Download diagnosis report as PDF
Includes:
Symptoms
Predicted disease
Confidence score
Precautions
✅ History Tracking
Stores previous diagnosis results during session
✅ Professional UI
Dark-themed diagnosis dashboard
Interactive sidebar navigation
Background image home page

⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/yourusername/AI-Medical-Diagnosis-System.git
2️⃣ Open Project Folder
cd AI-Medical-Diagnosis-System
3️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Run Application
streamlit run app.py

Application runs at:

http://localhost:8501
